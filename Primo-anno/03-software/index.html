Il software: i programmi del computer

Un computer può rappresentare dati con 0 e 1, ma chi gli indica quali operazioni eseguire? Scopriamo il ruolo dei programmi.

⏱️ 2 ore 📘 Primo anno 🎯 Dati binari, bit e byte
Percorso del primo anno Lezione 3 di 18
↩️

Prima di iniziare: richiamiamo la Lezione 02

Nella lezione precedente hai scoperto che il computer rappresenta numeri, testi, immagini e suoni mediante sequenze di bit. Un bit può valere 0 oppure 1 e otto bit formano un byte.

I dati binari, però, non indicano da soli che cosa deve fare il computer. Servono programmi formati da istruzioni che stabiliscano come elaborare quei dati.

💡

Collegamento tra le lezioni

Dai dati alle istruzioni

I dati rappresentano le informazioni. Il software è formato da programmi e ogni programma contiene istruzioni per lavorare con quei dati.

Una mattina con molti programmi

La sveglia del telefono suona. Controlli le previsioni del tempo, scrivi un messaggio, apri il browser e prepari una presentazione. Il dispositivo fisico è sempre lo stesso, ma svolge compiti diversi.

A cambiare è il programma utilizzato. L'app della sveglia controlla l'orario; il browser mostra pagine web; il programma di presentazione consente di organizzare testi e immagini in diapositive.

Sveglia

Confronta l'orario impostato con quello corrente e produce un avviso.

Browser

Permette di consultare e usare contenuti del Web.

Editor di testo

Permette di scrivere, correggere e organizzare un testo.

Calcolatrice

Riceve numeri e operazioni e restituisce un risultato.

🧾

Dagli esempi alla definizione

Software

È la parte logica del computer ed è costituito dall'insieme dei programmi.

Programma

Sequenza di istruzioni che permette al computer di svolgere uno specifico compito.

Nel linguaggio comune, “programma” e “applicazione” sono spesso usati come sinonimi. In questa lezione li considereremo equivalenti.

Il software è la parte logica e non si può toccare. L'hardware è invece la parte fisica. Software e hardware lavorano sempre insieme: quando avviamo un programma, il computer ne esegue le istruzioni.

❌

Errore frequente

Confondere il programma con il documento

Un editor di testo è un programma; la relazione scritta con quell'editor è un documento. Il programma permette di lavorare, mentre il documento contiene i dati prodotti dall'utente.

🔄

Software, utente e computer collaborano

Consideriamo una calcolatrice. L'utente inserisce due numeri e sceglie un'operazione. Il programma indica quali calcoli eseguire. Il computer esegue le istruzioni e mostra il risultato.

Utente Inserisce dati e sceglie un comando
→
Programma → Computer Il computer esegue le istruzioni del programma
→
Risultato Viene restituito all'utente

Lo stesso computer può quindi svolgere compiti differenti perché può eseguire programmi differenti. Senza software, non saprebbe quale attività svolgere.

🗂️

Due grandi categorie di software

Possiamo classificare il software osservando la sua funzione. Alcuni programmi rendono utilizzabile il sistema e sostengono il suo funzionamento; altri aiutano l'utente a svolgere attività specifiche.

Software di base

Gestisce le funzioni generali del sistema e crea le condizioni necessarie per eseguire gli altri programmi.

Esempi: sistema operativo e programmi di utilità.

Software applicativo

Aiuta l'utente a svolgere un compito specifico.

Esempi: browser, editor di testo, foglio di calcolo, lettore multimediale e programma di disegno.

💡

Criterio di classificazione

Chiediti quale funzione svolge

Se serve al funzionamento generale del sistema, è software di base. Se serve all'utente per un'attività specifica, è software applicativo.

⚙️

Il software di base

Quando accendi un dispositivo, alcuni programmi preparano l'ambiente necessario per usarlo. Coordinano le funzioni generali e permettono alle applicazioni di lavorare.

Sistema operativo

È il principale software di base e rende possibile l'uso organizzato del sistema. Sarà studiato in una lezione dedicata.

Strumenti di sistema

Aiutano a gestire le funzioni generali del computer.

Programmi di utilità

Svolgono attività di supporto e manutenzione del sistema.

In questa lezione è sufficiente riconoscere lo scopo generale di questi programmi. Il funzionamento dettagliato del sistema operativo verrà affrontato più avanti.

🧰

Il software applicativo

Le applicazioni rispondono a esigenze concrete dell'utente. Una stessa attività può essere svolta da programmi diversi: esistono, per esempio, molti browser e molti editor di testo.

Comunicare

Posta elettronica, messaggistica e videoconferenza.

Produrre contenuti

Scrittura, presentazioni, disegno e montaggio multimediale.

Calcolare e organizzare

Calcolatrice, foglio di calcolo e gestione di dati.

Consultare contenuti

Browser, lettori di documenti e riproduttori multimediali.

⚠️

Attenzione

La categoria non coincide con il nome del prodotto

“Browser” indica una funzione; il nome di uno specifico browser identifica un prodotto. All'esame è importante saper spiegare prima la funzione e poi fornire un esempio.

🧭

Scegliere il programma adatto

Non esiste un programma migliore per ogni situazione. La scelta dipende dal compito da svolgere.

Devo scrivere una relazione

Scelgo un editor o elaboratore di testi.

Devo fare calcoli su una tabella

Scelgo un foglio di calcolo.

Devo consultare un sito

Scelgo un browser.

Devo presentare un argomento

Scelgo un programma per presentazioni.

💻 Laboratorio guidato — Mappa del software

Obiettivo: osservare programmi realmente disponibili, riconoscerne la funzione e classificarli con una motivazione.

Usa il computer a disposizione e un foglio di carta oppure un editor di testo. Non installare né rimuovere programmi.

  1. Individua sei programmi.

    Cerca programmi già presenti: per esempio browser, calcolatrice, editor di testo, programma di disegno o lettore multimediale.

  2. Annota nome e funzione.

    Per ogni programma scrivi quale compito permette di svolgere. Evita definizioni come “serve per il computer”: sii specifico.

  3. Classifica gli esempi.

    Indica se ciascun programma è software di base o applicativo e aggiungi una breve motivazione.

  4. Osserva un'applicazione.

    Apri la calcolatrice o un editor di testo. Individua i dati che inserisci, il comando scelto e il risultato restituito.

  5. Confronta due applicazioni.

    Scegli due programmi applicativi e spiega perché sono adatti a compiti diversi.

  6. Prepara una sintesi orale.

    In un minuto presenta un esempio di software di base e uno di software applicativo, motivando la classificazione.

✅

Suggerimento operativo

Usa quattro colonne

Organizza il lavoro con: nome, funzione, categoria e motivazione. La motivazione è la parte più importante.

✍️

Esercizi di consolidamento

1. Trova l'intruso

Browser, editor di testo, sistema operativo, programma di disegno: individua l'elemento di categoria diversa e spiega perché.

2. Programma o dato?

Classifica: editor di testo, relazione scolastica, browser, fotografia digitale, calcolatrice.

3. Scegli lo strumento

Indica il tipo di applicazione adatto per scrivere una relazione, fare calcoli in tabella e consultare un sito.

4. Motiva la categoria

Spiega perché un sistema operativo è software di base e un browser è software applicativo.

🧠 Autoverifica

Rispondi prima a voce. Apri la risposta soltanto dopo.

1. Che cos'è il software?

È la parte logica del computer ed è costituito dall'insieme dei programmi.

2. Qual è la differenza tra programma e documento?

Il programma contiene istruzioni e permette di svolgere un compito; il documento contiene dati prodotti o usati dall'utente.

3. A che cosa serve il software di base?

Gestisce le funzioni generali del sistema e permette agli altri programmi di essere eseguiti.

4. A che cosa serve il software applicativo?

Permette all'utente di svolgere compiti specifici, come scrivere, calcolare, comunicare o consultare contenuti.

5. Perché la funzione è utile per classificare un programma?

Perché consente di capire se il programma sostiene il funzionamento generale del sistema oppure svolge un compito specifico per l'utente.

Glossario essenziale

Software
Parte logica del computer, costituita dall'insieme dei programmi.
Programma
Sequenza di istruzioni destinata a uno specifico compito.
Software di base
Software che sostiene il funzionamento generale del sistema.
Software applicativo
Software destinato a uno specifico compito dell'utente.
Applicazione
Programma progettato per svolgere una specifica attività.
Parte logica
Componente non fisica del computer, costituita dal software.
