File e cartelle

Abbiamo salvato un documento. Dove si trova? Come possiamo riconoscerlo, ritrovarlo e organizzarlo senza confonderlo con gli altri?

⏱️ 2 ore 📘 Primo anno 🎯 File, cartelle e percorsi
Percorso del primo anno Lezione 6 di 18
↩️

Prima di iniziare: richiamiamo la Lezione 05

Il sistema operativo gestisce le risorse del dispositivo, organizza l'ambiente di lavoro e permette alle applicazioni di accedere ai dati. Quando scriviamo una relazione o creiamo un'immagine, l'applicazione può affidare al sistema operativo il compito di salvarla.

Salvare non basta: dobbiamo anche assegnare un nome chiaro, scegliere una posizione e saper ritrovare il documento. Per farlo utilizziamo file, cartelle e un'organizzazione comprensibile.

💡

Collegamento tra le lezioni

Dal salvataggio all'organizzazione

Il sistema operativo consente di salvare e ritrovare documenti. Ora impariamo come riconoscere gli elementi conservati e come organizzarli in modo ordinato.

Una scrivania piena di documenti

Immagina di salvare ogni attività scolastica con nomi come documento1, nuovo o finale_finale, tutte nella stessa posizione. Dopo qualche settimana sarebbe difficile capire quale elemento aprire.

Anche nel computer serve un criterio: I documenti e molti altri contenuti vengono conservati in file, che possono essere raccolti in cartelle.. Nomi chiari e una struttura ordinata rendono più semplice ritrovare ciò che serve.

🧾

Dall'esempio alle definizioni

File

Un insieme di dati conservato con un nome. Può contenere, per esempio, testo, immagini, audio, video o istruzioni di un programma.

Cartella

Un contenitore usato per organizzare file e altre cartelle.

Un file contiene dati

relazione.docx può contenere il testo di una relazione; foto.jpg può contenere un'immagine.

Una cartella organizza

La cartella Italiano può contenere relazioni e sottocartelle dedicate a diversi argomenti.

❌

Errore frequente

Confondere file e cartella

Un file conserva dati; una cartella serve a organizzare file e altre cartelle. Le icone possono essere simili, ma la funzione è diversa.

🏷️

Nome ed estensione

Osserva il nome relazione_scienze.docx. La parte relazione_scienze descrive il contenuto; la parte .docx, dopo l'ultimo punto, è l'estensione.

Estensione

Parte finale del nome di un file che aiuta il sistema operativo a riconoscerne il tipo e ad associarlo a un'applicazione adatta.

L'estensione fornisce un'indicazione utile, ma non garantisce da sola quale sia il contenuto effettivo. Cambiare soltanto l'estensione non converte un file in un altro formato.

Testi e documenti

  • .txt: testo semplice;
  • .pdf: documento a impaginazione stabile;
  • .docx: documento di videoscrittura.

Dati e presentazioni

  • .xlsx: foglio di calcolo;
  • .pptx: presentazione.

Immagini

  • .jpg: immagine;
  • .png: immagine.

Contenuti multimediali e Web

  • .mp3: audio;
  • .mp4: video;
  • .html: pagina Web.

Il sistema operativo può associare ciascun tipo di file a un'applicazione. Per esempio, un file .pdf può essere aperto con un lettore di documenti e un file .jpg con un visualizzatore di immagini.

❌

Errore frequente

Pensare che rinominare l'estensione converta il file

Sostituire .jpg con .png nel nome non modifica il modo in cui i dati sono stati creati. Per convertire un formato serve un'applicazione adatta.

🌳

Cartelle, sottocartelle e gerarchia

Una cartella può contenere file e altre cartelle, chiamate sottocartelle. In questo modo si crea una struttura gerarchica: si parte da una cartella più generale e si procede verso elementi sempre più specifici. 

Documenti
└── Scuola
    ├── Italiano
    │   └── relazione.docx
    ├── Matematica
    │   └── esercizi.pdf
    └── Informatica
        ├── lezioni
        └── verifiche

Cartella principale

Documenti è il punto di partenza dello schema.

Sottocartelle

Scuola, Italiano e Matematica sono cartelle contenute in altre cartelle.

File

relazione.docx ed esercizi.pdf sono file collocati nelle rispettive cartelle.

Posizione

La posizione di un elemento dipende dalla sequenza di cartelle da attraversare per raggiungerlo.

❌

Errore frequente

Pensare che una cartella contenga soltanto file

Una cartella può contenere sia file sia altre cartelle. Le sottocartelle permettono di creare livelli di organizzazione.

🧭

Il percorso di un elemento

Percorso

Sequenza di cartelle che indica come raggiungere un file o una cartella partendo da una posizione iniziale.

Nello schema precedente, per raggiungere relazione.docx si attraversano:

Documenti Cartella iniziale
→
Scuola → Italiano Sottocartelle
→
relazione.docx File cercato

Possiamo descriverlo come: Documenti → Scuola → Italiano → relazione.docx.

In Windows, le diverse parti del percorso sono spesso separate dal carattere \: 

Documenti\Scuola\Italiano\relazione.docx

Altri sistemi operativi possono utilizzare separatori differenti.

🛠️

Operazioni fondamentali

Creare

Aggiungere una nuova cartella o produrre un nuovo file mediante un'applicazione.

Rinominare

Cambiare il nome di un elemento senza modificarne il contenuto o la posizione.

Copiare

Creare una seconda copia in un'altra posizione. L'originale rimane dove si trovava.

Spostare

Trasferire l'elemento in una nuova posizione. Nella posizione iniziale non rimane l'originale.

Eliminare

Rimuovere un elemento dalla sua posizione. Spesso viene spostato nel cestino e può essere ripristinato finché il cestino non viene svuotato.

💡

Differenza essenziale

Copiare non significa spostare

Dopo una copia esistono due elementi, in due posizioni. Dopo uno spostamento lo stesso elemento si trova soltanto nella nuova posizione.

❌

Errore frequente

Confondere copia e spostamento

Prima di eseguire l'operazione, chiediti se vuoi conservare anche l'elemento nella posizione iniziale. Se sì, devi copiarlo.

🔗

Originale e collegamento

Un collegamento è un elemento che rimanda a un file, a una cartella o a un'applicazione collocati altrove. Non è una seconda copia completa dell'originale.

Se elimini soltanto il collegamento, l'originale normalmente rimane nella sua posizione. Se l'originale viene spostato o eliminato, il collegamento potrebbe non riuscire più ad aprirlo.

✅

Nomi chiari e organizzazione coerente

Descrivi il contenuto

Preferisci relazione_scienze a documento1.

Usa un criterio stabile

Mantieni lo stesso ordine, per esempio materia, argomento e data quando serve.

Evita versioni confuse

Sostituisci finale_finale con un nome che indichi chiaramente versione o data.

Crea cartelle utili

Usa pochi livelli comprensibili. Troppe cartelle possono rendere più difficile ritrovare gli elementi.

❌

Errore frequente

Usare nomi generici o contraddittori

Nomi come nuovo, documento1 o finale_finale non aiutano a riconoscere il contenuto. Scegli parole brevi ma descrittive.

❌

Errore frequente

Confondere salvataggio ed eliminazione

Salvare conserva le modifiche; eliminare rimuove un elemento dalla sua posizione. Sono operazioni con scopi opposti.

💻 Laboratorio guidato — Organizza file e cartelle

Durata: circa 30–40 minuti. Obiettivo: creare e controllare una struttura ordinata, svolgendo le principali operazioni in sicurezza.

⚠️

Regole di sicurezza

Lavora soltanto nello spazio assegnato

  • Lavora soltanto nella cartella indicata dal docente.
  • Non modificare o cancellare file di altre persone.
  • Non usare dati personali nei file di prova.
  • Non cambiare impostazioni del computer.
  • Non svuotare il cestino.
  • Chiedi al docente prima di eliminare elementi non creati durante l'attività.

Crea questa struttura nella posizione indicata dal docente:

Laboratorio_file
├── Documenti
│   ├── Italiano
│   └── Informatica
├── Immagini
└── Consegna
  1. Crea la cartella principale.

    Crea Laboratorio_file. In molti sistemi Windows puoi usare Ctrl + Shift + N per creare una nuova cartella.

  2. Crea cartelle e sottocartelle.

    Riproduci esattamente la struttura indicata, controllando ogni nome prima di proseguire.

  3. Prepara file di prova.

    Crea con un'applicazione due semplici file senza dati personali, oppure usa i file forniti dal docente. Salvali in Documenti.

  4. Assegna nomi chiari.

    Usa nomi che descrivano il contenuto, per esempio appunti_italiano e schema_informatica.

  5. Rinomina un file.

    Cambia il nome senza alterare l'estensione. In Windows puoi selezionare l'elemento e usare F2.

  6. Copia un file.

    Copia un file in Consegna con Ctrl + C e Ctrl + V. Verifica che l'originale sia ancora presente.

  7. Sposta un altro file.

    Spostalo nella sottocartella adatta con Ctrl + X e Ctrl + V. Verifica che non sia più nella posizione iniziale.

  8. Confronta le operazioni.

    Spiega con una frase perché dopo la copia esistono due elementi, mentre dopo lo spostamento l'elemento cambia posizione.

  9. Elimina e ripristina un file di prova.

    Solo se il docente lo consente, elimina un file creato durante l'attività con Canc e ripristinalo dal cestino. Non svuotare il cestino. Se necessario, annulla con Ctrl + Z.

  10. Segui un percorso.

    Individua il file indicato dal docente partendo da Laboratorio_file e descrivi tutte le cartelle attraversate.

  11. Controlla il risultato.

    Confronta la struttura finale con la consegna. Correggi soltanto gli elementi creati da te.

⌨️

Suggerimento operativo

Le scorciatoie possono variare

Le combinazioni indicate sono comuni in Windows. In macOS, GNU/Linux e altri sistemi possono essere differenti: usa i comandi equivalenti mostrati dal sistema o indicati dal docente.

Esercizi di consolidamento

Puoi svolgere gli esercizi sul quaderno oppure rispondere a voce.

1. File o cartella?

Classifica: Immagini, foto.png, Scuola, relazione.pdf, Informatica.

2. Riconosci il contenuto

Associa .mp3, .pptx, .jpg, .xlsx e .html al tipo di contenuto più probabile.

3. Leggi la struttura

Nello schema della cartella Documenti, indica la cartella principale, tre sottocartelle e due file.

4. Ricostruisci il percorso

Scrivi il percorso per raggiungere esercizi.pdf partendo da Documenti.

5. Scegli un nome chiaro

Migliora i nomi nuovo.docx, documento1.pdf e finale_finale.pptx, spiegando il criterio scelto.

6. Copia o spostamento?

Vuoi conservare un file nella cartella originale e averlo anche in Consegna. Quale operazione scegli e perché?

7. Individua l'errore

“Per trasformare una foto in un PDF basta sostituire .jpg con .pdf”. Correggi la frase.

8. Descrivi le operazioni

Spiega in ordine come creeresti una cartella, rinomineresti un file e lo sposteresti nella nuova cartella.

🧠 Autoverifica

Rispondi prima a voce. Apri la risposta soltanto dopo.

1. Che cos'è un file?

È un insieme di dati conservato con un nome. Può contenere testo, immagini, audio, video o altri tipi di dati.

2. Che cos'è una cartella?

È un contenitore usato per organizzare file e altre cartelle.

3. A che cosa serve l'estensione?

Aiuta il sistema operativo a riconoscere il tipo di file e ad associarlo a un'applicazione adatta. Non garantisce da sola il contenuto effettivo.

4. Che cos'è una struttura gerarchica?

È un'organizzazione a livelli nella quale una cartella può contenere sottocartelle e file.

5. Che cos'è un percorso?

È la sequenza di cartelle che indica come raggiungere un elemento partendo da una posizione iniziale.

6. Qual è la differenza tra copiare e spostare?

Copiare crea un secondo elemento e lascia l'originale al suo posto; spostare trasferisce l'elemento in una nuova posizione.

7. Cambiare estensione converte il formato?

No. Cambiare soltanto il nome non modifica il modo in cui i dati sono stati creati. Serve un'applicazione adatta alla conversione.

8. Perché è utile scegliere nomi chiari?

Per riconoscere più facilmente il contenuto e ritrovare gli elementi senza doverli aprire uno per uno.

Glossario essenziale

File
Insieme di dati conservato con un nome.
Cartella
Contenitore che organizza file e altre cartelle.
Estensione
Parte finale del nome che aiuta a riconoscere il tipo di file.
Sottocartella
Cartella contenuta all'interno di un'altra cartella.
Gerarchia
Organizzazione a livelli di cartelle, sottocartelle e file.
Percorso
Sequenza di cartelle necessaria per raggiungere un elemento.
Copia
Secondo esemplare di un elemento conservato in un'altra posizione.
Spostamento
Trasferimento di un elemento dalla posizione iniziale a una nuova.
Cestino
Area in cui spesso vengono collocati temporaneamente gli elementi eliminati.
Collegamento
Elemento che rimanda a un originale collocato altrove.
