Contenuti della mappa in forma testuale

1. Hardware

L'hardware è la parte fisica del computer: comprende tutto ciò che può essere toccato.

  • Unità centrale: CPU, RAM, scheda madre, SSD o HDD.
  • Periferiche di input: tastiera, mouse, scanner e microfono. Servono per inserire dati e comandi.
  • Periferiche di output: monitor, stampante e altoparlanti. Servono per comunicare i risultati.

2. Software

Il software è la parte logica del computer, formata da programmi e istruzioni.

  • Software di sistema: sistema operativo, driver e programmi di utilità.
  • Software applicativo: elaboratore di testi, foglio di calcolo, browser, giochi e applicazioni.

3. Dati

I dati sono le informazioni elaborate dal computer. Possono essere numeri, testi, immagini, suoni e video.

4. Hardware e software collaborano

Il funzionamento del computer può essere seguito in quattro passaggi:

  1. Utente: fornisce dati e comandi.
  2. Software: stabilisce quali operazioni eseguire.
  3. Hardware: esegue materialmente le operazioni.
  4. Risultato: il computer produce o mostra il risultato.

Utente → software → hardware → risultato

Da ricordare: hardware e software sono entrambi necessari e funzionano insieme.
