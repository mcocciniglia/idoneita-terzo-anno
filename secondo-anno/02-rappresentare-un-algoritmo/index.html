Prima di iniziare: dal diagramma alle istruzioni

Nella 2.01 hai costruito con Flowgorithm un diagramma per calcolare il costo dei biglietti. Hai distinto gli ingressi, l'elaborazione e l'uscita: numero dei biglietti e prezzo unitario entrano, il prodotto viene calcolato, il totale viene mostrato.

Ripercorri il diagramma senza avviarlo. Con quattro biglietti da 2,50 euro, quale valore deve apparire? Se cambi soltanto il prezzo in 3 euro, quale dato rimane uguale e quale risultato cambia? Questa previsione serve anche quando scrivi codice.

Nel diagramma ogni forma ha un compito: il parallelogramma legge o mostra un dato, il rettangolo esegue un calcolo. Nel programma troverai istruzioni scritte al posto dei blocchi. Il procedimento resta lo stesso; per eseguirlo dovrai rispettare la sintassi del linguaggio.

Un algoritmo è il procedimento; un diagramma, lo pseudocodice e il codice sono modi per rappresentarlo. Il codice C++ può essere tradotto da un compilatore in un programma eseguibile. Non occorre ricopiare ogni esercizio in tutte e tre le forme.

Prima di proseguire: scrivi input, calcolo e output dei biglietti. Spiega perché devi leggere i dati prima di moltiplicarli. Se non riesci, riprendi il laboratorio della 2.01; se riesci, sei pronto per la traduzione.

Che cosa farai oggi

  • Creare, compilare ed eseguire un file C++.
  • Usare variabili intere e decimali, input e output.
  • Tradurre una formula e controllarla con dati di prova.

Circa due ore: 15 minuti di raccordo e ambiente, 35 per il primo programma, 10 di pausa, 40 di esercizi e 20 di verifica. Puoi riprendere gli esercizi a casa se il primo avvio richiede più tempo.

Il costo dei biglietti, questa volta in C++

Leggi il programma prima di copiarlo. Cerca i nomi quantita, prezzo e totale. Inserirai prima la quantità, poi il prezzo; il programma mostrerà soltanto il totale.

Scarica biglietti.cpp

#include <iostream>

int main() {
    int quantita = 0;
    double prezzo = 0.0;
    std::cin >> quantita;
    std::cin >> prezzo;
    double totale = quantita * prezzo;
    std::cout << totale << '\n';
    return 0;
}

Preparare gli strumenti

#include <iostream> rende disponibili gli strumenti di input e output usati qui. Non è un'istruzione di calcolo e non termina con il punto e virgola.

Dove si comincia

int main() introduce la funzione da cui inizia il programma. Le parentesi graffe racchiudono le sue istruzioni. Per ora usa questo modello senza studiare le funzioni in generale.

Inserire e mostrare

std::cin >> quantita; legge un valore. std::cout << totale; mostra il risultato. std:: indica strumenti della libreria standard: conserva questa scrittura negli esempi.

Terminare

'\n' manda a capo l'output. return 0; conclude il programma segnalando una terminazione regolare. Le istruzioni di lettura, calcolo e output terminano con ;.

Laboratorio guidato: scrivere, compilare, eseguire

  1. Apri l'ambiente indicato dal docente.

    Crea un progetto o un file per C++, non per C. Salvalo come biglietti.cpp. Puoi partire dal file scaricabile.

  2. Scrivi il modello completo.

    Conserva maiuscole, simboli, graffe e punto e virgola. Il nome del file e quello delle variabili hanno funzioni diverse.

  3. Compila.

    Usa il comando Compila o Build dell'ambiente. Il compilatore controlla il codice e lo traduce. Se segnala un errore, leggi il primo messaggio e controlla anche la riga precedente.

  4. Esegui.

    Avvia il programma. Nella console digita 4 e premi Invio; poi digita 2.5 e premi Invio. Se la console aspetta dopo il primo numero, sta attendendo il secondo input.

  5. Confronta.

    Devi leggere 10. È lo stesso valore di 10,00 euro: la formattazione con due decimali verrà ripresa più avanti.

  6. Modifica e ricompila.

    Prova 3 biglietti da 7 euro: devi ottenere 21. Ogni modifica del sorgente richiede una nuova compilazione prima dell'esecuzione della versione aggiornata.

Se lavori da un terminale con GNU C++ già predisposto, puoi compilare con g++ -std=c++17 biglietti.cpp -o biglietti. L'avvio dipende dal sistema: ./biglietti su Linux, .\biglietti.exe in PowerShell su Windows. Nell'ambiente grafico usa il suo pulsante Esegui.

Che cosa conservano le variabili

int quantita = 0; crea una variabile per un numero intero e le assegna un valore iniziale. double prezzo = 0.0; prepara un numero che può avere una parte decimale. La lettura successiva sostituisce il valore iniziale.

Una variabile ha un nome, un tipo e un valore. int è adatto a una quantità intera; double a una misura decimale. I valori rappresentabili sono limitati: negli esercizi usiamo numeri piccoli. double rappresenta molti decimali in modo approssimato; questi esempi non sono un modello di contabilità professionale.

Un nome significativo, come prezzo, aiuta a capire il ruolo del dato. Nel corso usiamo lettere, cifre e underscore; non iniziamo con una cifra, non usiamo spazi e rispettiamo maiuscole e minuscole. prezzo e Prezzo sono nomi diversi.

L'assegnazione totale = quantita * prezzo; valuta prima la parte destra e memorizza il risultato a sinistra. Il simbolo = assegna: non è un'affermazione di uguaglianza matematica.

int numero = 5;
numero = numero + 1;

La seconda riga legge 5, calcola 6 e sostituisce il valore precedente. In una traccia scrivi una riga per ogni aggiornamento.

Controlla le tre assegnazioni

Con a = 4;, b = 3;, a = a + b;, b = a * 2;, i valori finali sono a = 7 e b = 14. L'ultima istruzione usa il nuovo valore di a.

Una variabile letta da input resta una variabile anche se non viene più modificata. Se un valore deve essere fisso nel programma, puoi dichiararlo con const, per esempio const double PI_GRECO = 3.14159;: il programma non può riassegnarlo. Questa è un'approssimazione scelta per l'esercizio.

Dalla formula al codice

Per moltiplicare si usa *, non il simbolo matematico ×. I simboli +, - e / indicano somma, sottrazione e divisione. Le parentesi rendono esplicito il raggruppamento: 2 + 3 * 4 vale 14, mentre (2 + 3) * 4 vale 20.

In 10 + 6 / 2 * 3, prima si eseguono divisione e moltiplicazione da sinistra a destra: 6 / 2 dà 3, 3 * 3 dà 9, poi 10 + 9 dà 19. L'operatore agisce sugli operandi; l'intera espressione produce un valore.

Scarica divisione.cpp

#include <iostream>

int main() {
    std::cout << 8 / 3 << '\n';
    std::cout << 8.0 / 3 << '\n';
    std::cout << 8 % 3 << '\n';
    return 0;
}

Le tre righe mostrano 2, circa 2.66667 e 2. Con due operandi interi, / produce un quoziente intero troncato verso zero. Con 8.0 la divisione usa un tipo decimale. % calcola il resto fra interi: qui 8 = 3 × 2 + 2. Non usare mod come in Flowgorithm.

⚠️

Attenzione

Il tipo del risultato non corregge il calcolo

Anche double risultato = 8 / 3; memorizza 2: la divisione è già avvenuta fra interi. Usa 8.0 / 3. Non dividere per zero e, nei dati digitati, usa il punto: 2.5.

Esercizio guidato: rettangolo

Leggi base e altezza positive. Calcola area e perimetro. Prima scrivi le formule sul quaderno; poi confrontale con il programma.

Scarica rettangolo.cpp

#include <iostream>

int main() {
    double base = 0.0;
    double altezza = 0.0;
    std::cin >> base >> altezza;
    double area = base * altezza;
    double perimetro = 2 * (base + altezza);
    std::cout << area << '\n';
    std::cout << perimetro << '\n';
    return 0;
}
  1. Individua i due input e i due output.
  2. Nota che std::cin >> base >> altezza; esegue due letture in ordine; puoi separare i numeri con uno spazio o con Invio.
  3. Prova base 5 e altezza 3: area 15, perimetro 16.
  4. Prova 2.5 e 2: area 5, perimetro 9.
  5. Togli temporaneamente le parentesi dalla formula del perimetro. Con 5 e 3 ottieni 13: spiega perché la formula è sbagliata, poi ripristinala.

Ora prova tu: media di tre misure

Scrivi un programma che legga tre misure e mostri la loro media aritmetica. Usa tre variabili double, parentesi attorno alla somma e divisione per 3.0. Prova prima 6, 7, 8: risultato 7. Poi 1, 2, 2: risultato circa 1,66667.

Apri una possibile soluzione

Scarica media.cpp

#include <iostream>

int main() {
    double a = 0.0;
    double b = 0.0;
    double c = 0.0;
    std::cin >> a >> b >> c;
    double media = (a + b + c) / 3.0;
    std::cout << media << '\n';
    return 0;
}

Consegna: il file .cpp, i due gruppi di input e i risultati ottenuti. Spiega perché a + b + c / 3.0 non calcola la media.

Quando qualcosa non funziona

  • Errore di compilazione: controlla ;, graffe e nomi prima di cambiare la formula.
  • Il programma sembra fermo: controlla quanti input sta aspettando.
  • Il risultato è sbagliato: scegli dati semplici e ricostruisci le operazioni; compilare non dimostra la correttezza del calcolo.
  • Hai modificato il sorgente ma non l'output: salva e ricompila, verificando quale eseguibile avvii.

In questa lezione assumiamo input numerici validi: quantità intere non negative, prezzi non negativi e piccoli. Le lettere al posto dei numeri e la gestione completa degli errori di input saranno affrontate dopo i primi programmi.

Autoverifica

Rispondi prima di aprire le indicazioni.

Che cosa cambia fra sorgente ed eseguibile?

Il sorgente è il testo del programma; il compilatore lo traduce per ottenere un eseguibile avviabile.

Quanto vale numero dopo numero = numero + 1, se prima vale 5?

Vale 6. Prima si legge il valore precedente, poi si calcola e si assegna.

Perché 8 / 3 e 8.0 / 3 danno risultati diversi?

Nel primo caso entrambi gli operandi sono interi; nel secondo uno è double e il risultato della divisione può avere parte decimale.

Quando puoi passare alla prossima lezione?

Quando sai compilare il programma della media, provarlo con due gruppi di dati e spiegare input, formula e output.
