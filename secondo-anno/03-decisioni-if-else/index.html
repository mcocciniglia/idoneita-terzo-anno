Prendere decisioni con if e else

Usare una condizione per scegliere il percorso e controllare i valori di soglia.

Prima di iniziare: una scelta già incontrata

Nella 2.02 hai tradotto il diagramma dei biglietti in un programma: leggi i dati, esegui una moltiplicazione e mostri il totale. int conserva una quantità intera; double permette di lavorare con prezzi e misure decimali.

Riprendi il file dei biglietti. Con 4 e 2.5 il totale è 10. Ora immagina di avere un budget di 9 euro: il programma dovrebbe mostrare un messaggio diverso rispetto a un budget di 12 euro. Non basta aggiungere sempre lo stesso output.

Questo problema non è nuovo: nella 2.01 il rombo di Flowgorithm aveva già separato i due percorsi. Ora devi esprimere la stessa decisione nel codice. Il confronto produce vero o falso, e il programma esegue le istruzioni del ramo corrispondente.

Prima di leggere il codice, prevedi tre casi: costo 10 e budget 9; costo 10 e budget 10; costo 10 e budget 11. Il caso di uguaglianza decide quale confronto è adatto. Scrivi anche quale dato è il totale e quale è la disponibilità.

Se hai dubbi sull'assegnazione, segui a mano int x = 5; e x = x + 1;. La seconda riga cambia il valore. La domanda «x è uguale a 6?» richiederà un operatore diverso: confrontare e assegnare svolgono compiti distinti.

Obiettivi e lavoro previsto

  • Scrivere selezioni semplici e doppie con if ed else.
  • Distinguere assegnazione e confronto.
  • Provare rami e soglie prima di considerare corretto il programma.

Circa due ore: 15 minuti di ripasso, 30 per condizioni e budget, 10 di pausa, 45 di laboratorio, 20 di verifica.

Esempio: il budget basta?

Inserisci nell'ordine il costo totale e il budget. Quando il budget è uguale al costo, è sufficiente: la condizione usa >=.

Scarica budget.cpp

#include <iostream>

int main() {
    double totale = 0.0;
    double budget = 0.0;
    std::cin >> totale >> budget;
    if (budget >= totale) {
        std::cout << "Budget sufficiente\n";
    } else {
        std::cout << "Budget insufficiente\n";
    }
    return 0;
}

if significa «se». La condizione è fra parentesi tonde. Se è vera, vengono eseguite le istruzioni del primo blocco; altrimenti si esegue il blocco di else. Dopo il ramo scelto, il flusso prosegue dopo l'intera selezione.

Input 10 e 9

9 ≥ 10 è falso: Budget insufficiente.

Input 10 e 10

10 ≥ 10 è vero: Budget sufficiente.

Input 10 e 11

11 ≥ 10 è vero: Budget sufficiente.

Questa è una selezione doppia: a ogni esecuzione viene scelto uno solo dei due rami. Il compilatore non verifica se hai scelto la soglia giusta per il problema: servono i test.

I confronti da scrivere nel codice

  • a < b: a è minore di b.
  • a > b: a è maggiore di b.
  • a <= b e a >= b: includono l'uguaglianza.
  • a == b: i due valori sono uguali.
  • a != b: i due valori sono diversi.

Il risultato di un confronto è un valore logico: true oppure false. In italiano lo leggiamo vero oppure falso.

⚠️

Attenzione

Un solo = non confronta

numero = 0; assegna zero. numero == 0 verifica se il valore è zero. Scrivere un’assegnazione dentro if può compilare e cambiare la variabile: per questo va controllata anche la logica.

Scriviamo sempre le graffe dei blocchi. Non mettere un punto e virgola dopo la condizione: if (numero > 0); contiene un'istruzione vuota e non controlla il blocco successivo come ti aspetti.

Un messaggio soltanto in un caso

Se vuoi mostrare «Positivo» soltanto per valori maggiori di zero, basta una selezione semplice, senza else.

Scarica positivo.cpp

#include <iostream>

int main() {
    double numero = 0.0;
    std::cin >> numero;
    if (numero > 0) {
        std::cout << "Positivo\n";
    }
    return 0;
}

Con 5 compare il messaggio. Con 0 e con -2 non compare alcun messaggio: non è un blocco del programma. La condizione è falsa e l'output viene saltato. Zero non è un numero positivo.

Laboratorio guidato: ingresso al museo

Un museo offre l'ingresso gratuito fino a 12 anni compresi. Scrivi un programma che legga l'età intera e mostri «Ingresso gratuito» oppure «Biglietto ordinario». Assumi un'età valida fra 0 e 120.

  1. Prepara un nuovo file museo.cpp con il modello della lezione precedente.
  2. Dichiara e leggi eta.
  3. Scrivi sul quaderno il risultato atteso per 11, 12 e 13.
  4. Formula il confronto: il valore 12 deve appartenere al ramo gratuito.
  5. Completa entrambi i blocchi e compila.
  6. Esegui tre volte il programma, una per ogni dato. Confronta previsione e risultato.
Controlla la soluzione

Scarica museo.cpp

#include <iostream>

int main() {
    int eta = 0;
    std::cin >> eta;
    if (eta <= 12) {
        std::cout << "Ingresso gratuito\n";
    } else {
        std::cout << "Biglietto ordinario\n";
    }
    return 0;
}

11 e 12 devono dare ingresso gratuito, 13 biglietto ordinario. Sostituire <= con < mantiene corretti alcuni casi e sbaglia proprio la soglia.

Esercizio autonomo: zero oppure diverso da zero

Leggi un intero e mostra «Zero» quando è uguale a zero, «Diverso da zero» negli altri casi. Scegli il confronto, scrivi il programma e prova 0, 4 e -1.

Suggerimento

Servono due output alternativi, quindi usa if/else. Il confronto è numero == 0.

Apri una possibile soluzione

Scarica zero.cpp

#include <iostream>

int main() {
    int numero = 0;
    std::cin >> numero;
    if (numero == 0) {
        std::cout << "Zero\n";
    } else {
        std::cout << "Diverso da zero\n";
    }
    return 0;
}

Consegna: sorgente e tre prove. Spiega la differenza fra il caso con else e il programma che mostra soltanto i positivi.

Leggere una selezione senza eseguirla

  1. Annota il valore letto.
  2. Sostituiscilo nella condizione.
  3. Scrivi vero o falso.
  4. Segui soltanto il ramo scelto.
  5. Registra l'output, poi riparti dall'input per la prova successiva.

Non usare un solo input per verificare una selezione doppia. Scegli almeno un caso per ramo e, quando esiste una soglia, un valore subito sotto, uno uguale e uno subito sopra.

Autoverifica

Rispondi prima di aprire le indicazioni.

Il budget uguale al costo è sufficiente?

Sì. Per questo il confronto è budget >= totale.

Vengono eseguiti entrambi i rami di if/else?

No: per una singola valutazione della condizione viene scelto un solo ramo.

Che cosa succede con 0 nel programma positivo?

La condizione numero > 0 è falsa: il messaggio viene saltato.

Che cosa provi per la soglia 12 inclusa?

11, 12 e 13: gratuito nei primi due casi, ordinario nel terzo.
