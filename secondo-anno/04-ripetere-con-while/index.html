Ripetere con while

Prima di iniziare: condizione e aggiornamento

Nella 2.03 hai fatto scegliere al programma fra due percorsi. Prima leggi i dati, poi valuti una condizione e segui il ramo vero o quello falso. Nel programma del museo, 12 anni rientra nell'ingresso gratuito perché il confronto include la soglia.

Riprendi ora un aggiornamento della 2.02: numero = numero + 1;. Se numero vale 2, il nuovo valore è 3. La variabile a sinistra riceve il risultato del calcolo a destra; non stai scrivendo un'uguaglianza matematica.

Immagina di voler mostrare i numeri da 1 a 5. Puoi scrivere cinque output, ma se il limite diventa 100 devi allungare il programma. Conviene ripetere la stessa coppia di azioni: mostra il numero, poi aumentalo di uno.

Per decidere quando continuare puoi chiedere: «Il numero è ancora minore o uguale a 5?». La condizione ricorda quella di un if, ma verrà controllata di nuovo dopo ogni ripetizione.

Prima di leggere il codice, scrivi sul quaderno tre elementi: valore iniziale, condizione per continuare e aggiornamento. Poi prevedi quale valore avrà la variabile quando il programma avrà già mostrato 5. Questa previsione ti aiuterà a distinguere il valore mostrato dal valore finale.

Che cosa imparerai

  • Scrivere un ciclo while e riconoscerne il corpo.
  • Usare una variabile di controllo e un accumulatore.
  • Provare zero, una e più iterazioni e correggere un aggiornamento mancante.

Circa due ore: 15 minuti di raccordo, 25 di conteggio e traccia, 10 di pausa, 45 di laboratorio sulla somma, 25 di esercizio e verifica.

Mostrare i numeri da 1 a 5

Nel programma seguente, dopo ogni output il valore aumenta di uno. Prevedi l'output prima di eseguirlo.

Scarica conteggio-while.cpp

#include <iostream>

int main() {
    int numero = 1;
    while (numero <= 5) {
        std::cout << numero << '\n';
        numero = numero + 1;
    }
    return 0;
}

Un ciclo ripete un gruppo di istruzioni; ogni esecuzione del corpo è un'iterazione. while significa «mentre»: il corpo si esegue finché la condizione è vera.

Inizializzazione

int numero = 1; si esegue prima del ciclo, una sola volta.

Controllo

numero <= 5 viene valutata prima di ogni possibile giro.

Aggiornamento

numero = numero + 1; sta nel corpo, dopo l'output.

Seguire il ciclo un giro alla volta

  1. Numero 1: condizione vera, mostra 1, aggiorna a 2.
  2. Numero 2: condizione vera, mostra 2, aggiorna a 3.
  3. Numero 3: condizione vera, mostra 3, aggiorna a 4.
  4. Numero 4: condizione vera, mostra 4, aggiorna a 5.
  5. Numero 5: condizione vera, mostra 5, aggiorna a 6.
  6. Numero 6: condizione falsa; esci senza mostrare 6.

Ci sono cinque iterazioni e sei controlli. Il controllo finale falso non esegue il corpo. Con un valore iniziale pari a 6 il corpo non si eseguirebbe neppure una volta: while ammette zero iterazioni.

Disegna su carta tre colonne: valore prima del controllo, output e valore dopo l'aggiornamento. Compila anche l'ultima riga con la condizione falsa.

Laboratorio guidato: sommare da 1 a N

Leggi un intero N fra 0 e 100. Calcola 1 + 2 + … + N. Con N = 4 il risultato atteso è 10; con N = 0 non ci sono numeri da aggiungere e il risultato è 0.

Scarica somma-while.cpp

#include <iostream>

int main() {
    int n = 0;
    std::cin >> n;
    int numero = 1;
    int somma = 0;
    while (numero <= n) {
        somma = somma + numero;
        numero = numero + 1;
    }
    std::cout << somma << '\n';
    return 0;
}

numero controlla il giro. somma è un accumulatore: conserva il totale parziale e parte da zero, che non altera una somma.

  1. Leggi il programma e distingui input, inizializzazioni, corpo e output finale.
  2. Con N = 4, scrivi i totali parziali: 1, 3, 6, 10.
  3. Compila ed esegui con 4, poi confronta il risultato.
  4. Ripeti con N = 1: un'iterazione, risultato 1.
  5. Ripeti con N = 0: zero iterazioni, risultato 0.
  6. Usa il debugger o una traccia su carta per spiegare perché numero arriva a 5 quando N vale 4.

L'output di somma è dopo il ciclo: mostra il risultato finale una sola volta. Se vuoi osservare i totali parziali, puoi aggiungere temporaneamente un output nel corpo e poi rimuoverlo.

Quando la ripetizione non termina

Se elimini l'aggiornamento dal conteggio, numero resta 1 e la condizione rimane vera. Questo ciclo non raggiunge l'uscita. Se lo avvii per errore, usa Interrompi/Stop nell'ambiente oppure Ctrl+C nel terminale.

⚠️

Attenzione

Tre controlli prima di avviare

Dove parte la variabile? Quale condizione permette un altro giro? Quale istruzione avvicina all’uscita? Per leggere l’esempio non serve avviare un ciclo che sai già non terminare.

  • Inizializzare somma dentro il ciclo cancella ogni volta il totale precedente.
  • Aggiornare il numero prima di aggiungerlo cambia i numeri sommati.
  • Con numero < N il valore N non viene sommato.
  • Diminuire un numero partito da 1 mentre controlli numero <= 5 lo allontana dall'uscita.

Esercizio autonomo: multipli di 3

Leggi un limite intero fra 0 e 100. Mostra tutti i multipli positivi di 3 che non lo superano. Con limite 10 devi mostrare 3, 6, 9; con 2 nessun numero; con 3 soltanto 3.

  1. Scegli valore iniziale e variabile di controllo.
  2. Scrivi la condizione includendo il limite.
  3. Decidi di quanto aumentare il multiplo.
  4. Prevedi i tre casi indicati, poi compila ed esegui.
Suggerimento

Parti da multiplo = 3, continua mentre multiplo <= limite e aumenta di 3 dopo ogni output.

Controlla una soluzione completa

Scarica multipli.cpp

#include <iostream>

int main() {
    int limite = 0;
    std::cin >> limite;
    int multiplo = 3;
    while (multiplo <= limite) {
        std::cout << multiplo << '\n';
        multiplo = multiplo + 3;
    }
    return 0;
}

Consegna: file, tre prove e una breve spiegazione del caso senza output. Assumiamo input numerici validi entro gli intervalli indicati.

Autoverifica

Rispondi prima di aprire le indicazioni.

Quante volte può eseguire il corpo un while?

Zero o più volte: il controllo precede ogni possibile esecuzione.

Perché somma parte da zero?

Zero è l’elemento neutro della somma e permette il risultato corretto anche senza iterazioni.

Con N=4, quanto valgono somma e numero dopo il ciclo?

Somma vale 10, numero vale 5. L’ultimo controllo è falso.

Che differenza c’è fra if e while?

If sceglie se eseguire un blocco; while torna a controllare la condizione e può ripetere il corpo.
