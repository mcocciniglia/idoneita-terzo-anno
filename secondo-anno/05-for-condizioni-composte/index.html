Il ciclo for e le condizioni composte

Contare i giri e combinare confronti per elaborare un dato alla volta.

Prima di iniziare: i tre elementi del ciclo

Nella 2.04 hai scritto un while per mostrare da 1 a 5 e un altro per sommare da 1 a N. Prima del ciclo inizializzi le variabili; prima di ogni giro controlli una condizione; nel corpo aggiorni i valori.

Ripeti il conteggio a voce: numero 1, controllo vero, output 1, aggiornamento a 2. Prosegui fino al controllo falso con numero 6. Il corpo viene eseguito cinque volte; il controllo finale non aggiunge un'iterazione.

Ricorda anche la differenza fra i ruoli. La variabile di controllo determina il proseguimento del ciclo; un accumulatore conserva un risultato progressivo. Se sommi da 1 a N, numero e somma non sono intercambiabili.

Ora pensa a una serie di cinque misure. Non vuoi soltanto leggerle: vuoi contare quante appartengono a un intervallo. Servono una ripetizione per acquisire tutte le misure e una decisione per scegliere quali contare.

Prima di proseguire, segui questa sequenza: 9, 10, 15, 20, 21. Se l'intervallo comprende 10 e 20, quanti valori sono dentro? Scrivi il risultato previsto e motiva i due confini. Non serve conservare tutti i valori: puoi controllarne uno alla volta.

Due attività che puoi separare

La lezione comprende due blocchi: for e condizioni composte. Puoi svolgerli in due incontri più brevi. Prima completa il conteggio; poi unisci ciclo e selezione.

  • Tradurre un conteggio da while a for.
  • Usare &&, || e ! in condizioni leggibili.
  • Distinguere numero del giro, valore letto e conteggio dei casi favorevoli.

Circa due ore: 15 minuti di ripasso, 25 per for, 10 di pausa, 25 per le condizioni, 30 di laboratorio e 15 di verifica.

Lo stesso conteggio con for

Il ciclo seguente produce lo stesso output del primo while della 2.04.

Scarica conteggio-for.cpp

#include <iostream>

int main() {
    for (int i = 1; i <= 5; i = i + 1) {
        std::cout << i << '\n';
    }
    return 0;
}

Nell'intestazione ci sono tre parti, separate da due punti e virgola: int i = 1 inizializza; i <= 5 decide se eseguire un altro giro; i = i + 1 aggiorna dopo il corpo.

  1. L'inizializzazione avviene una volta sola.
  2. La condizione viene controllata prima del corpo.
  3. Se è vera, si esegue il corpo e poi l'aggiornamento.
  4. Si torna al controllo; quando è falso si prosegue dopo il ciclo.

i è un nome breve convenzionale per un indice di conteggio. Dichiarato nell'intestazione, esiste nel ciclo e non è disponibile dopo la sua chiusura. Nel nostro esempio assume 1–5 nel corpo; dopo l'ultimo aggiornamento arriva a 6 per il controllo finale.

Confronta il sorgente con conteggio-while.cpp: evidenzia le tre parti corrispondenti. Non aggiungere nel corpo un secondo aggiornamento di i.

Dentro un intervallo: servono entrambi i limiti

Per appartenere all'intervallo da 10 a 20 inclusi, un valore deve essere almeno 10 e al massimo 20. Con 25 il primo confronto è vero, ma il secondo è falso: il valore è fuori.

Scarica intervallo.cpp

#include <iostream>

int main() {
    int valore = 0;
    std::cin >> valore;
    bool dentro = (valore >= 10) && (valore <= 20);
    if (dentro) {
        std::cout << "Dentro\n";
    } else {
        std::cout << "Fuori\n";
    }
    return 0;
}

bool è il tipo per un valore logico: può contenere true o false. Qui dentro conserva il risultato della condizione composta.

AND: &&

Richiede che entrambi i confronti siano veri. (valore >= 10) && (valore <= 20) riconosce i valori dentro.

OR inclusivo: ||

Basta almeno un confronto vero, anche entrambi. (valore < 10) || (valore > 20) riconosce i valori fuori.

NOT: !

Nega un risultato. !dentro è vero quando dentro è falso. Per negare un confronto, scrivi per esempio !(valore >= 10).

In una condizione con &&, se la prima parte è falsa la seconda non viene valutata; con ||, se la prima è vera la seconda non viene valutata. Negli esempi usiamo confronti senza effetti sulle variabili.

⚠️

Attenzione

Non concatenare i confronti come in matematica

Per l’intervallo non scrivere 10 <= valore <= 20. Scrivi due confronti collegati da &&. Le parentesi separano le due domande.

Prova 9 e 21: fuori. Prova 10, 15 e 20: dentro. OR è inclusivo: nella condizione (eta < 18) || (acquisti >= 5), età 16 e 7 acquisti soddisfano entrambe le parti e il risultato è comunque vero.

Laboratorio: contare i valori dentro

Leggi N, poi N interi. Conta quanti appartengono a [10, 20]. Assumi N fra 0 e 100 e valori fra -100 e 100.

Scarica conta-intervallo.cpp

#include <iostream>

int main() {
    int n = 0;
    std::cin >> n;
    int conteggio = 0;
    for (int i = 0; i < n; i = i + 1) {
        int valore = 0;
        std::cin >> valore;
        if ((valore >= 10) && (valore <= 20)) {
            conteggio = conteggio + 1;
        }
    }
    std::cout << conteggio << '\n';
    return 0;
}
  1. Inserisci N = 5 e poi 9, 10, 15, 20, 21. Prima di avviare, prevedi il conteggio: 3.
  2. Distingui i, che conta i giri da 0 a N escluso, e valore, che riceve l'input corrente.
  3. Osserva conteggio: aumenta soltanto nel ramo vero della selezione.
  4. Ricostruisci i conteggi parziali dopo i cinque input: 0, 1, 2, 3, 3.
  5. Prova N = 0: nessun input successivo, risultato 0. Prova N = 1 e valore 10: risultato 1.

La lettura è nel corpo, quindi viene ripetuta N volte. Non occorre un array: ogni valore viene usato e può essere sostituito al giro seguente. N è il numero dei dati, non l'ultimo valore da inserire.

Esercizio autonomo: cinque numeri, quanti positivi?

Leggi esattamente cinque interi e mostra quanti sono maggiori di zero. Qui non si legge N: il numero di giri è già nella consegna.

Con -2, 0, 4, 1, -1 devi ottenere 2. Con cinque zeri devi ottenere 0. Con 1, 2, 3, 4, 5 devi ottenere 5. Spiega perché zero non viene contato.

Apri una possibile soluzione

Scarica cinque-positivi.cpp

#include <iostream>

int main() {
    int positivi = 0;
    for (int i = 0; i < 5; i = i + 1) {
        int numero = 0;
        std::cin >> numero;
        if (numero > 0) {
            positivi = positivi + 1;
        }
    }
    std::cout << positivi << '\n';
    return 0;
}

Consegna: il sorgente, i tre casi e una traccia che mostri separatamente indice e conteggio.

Approfondimento breve: tre casi

Una decisione può trovarsi dentro il ramo di un'altra. Per classificare un numero, prima chiedi se è positivo; soltanto se non lo è chiedi se è negativo. Se entrambi i confronti sono falsi, il numero è zero.

if (numero > 0) {
    std::cout << "Positivo\n";
} else if (numero < 0) {
    std::cout << "Negativo\n";
} else {
    std::cout << "Zero\n";
}

Questo è un frammento da inserire in main dopo dichiarazione e lettura di numero. Con 8, il secondo confronto non viene raggiunto. Non occorre moltiplicare gli annidamenti per risolvere gli esercizi principali.

Autoverifica

Rispondi prima di aprire le indicazioni.

Quanti giri esegue for con i=0, i<n e incremento di 1, se n=5?

Cinque: con i uguale a 0, 1, 2, 3 e 4.

Per stare dentro [10,20] usi AND oppure OR?

AND, perché entrambi i limiti devono essere rispettati.

OR è vero quando entrambe le parti sono vere?

Sì. È un OR inclusivo.

Perché i e conteggio possono essere diversi?

I conta i giri; conteggio conta soltanto gli input che soddisfano la condizione.
