Prima di iniziare: leggere un programma completo

Ora sai costruire piccoli programmi C++ da console. Una sequenza legge e calcola; una selezione sceglie un ramo; un ciclo ripete un gruppo di istruzioni. Per controllare il risultato usi una previsione e una serie di prove.

Nella 2.05 hai distinto tre variabili: l'indice del giro, il valore appena letto e il conteggio dei dati accettati. Nel programma dell'intervallo, un valore sostituisce il precedente a ogni lettura, mentre il conteggio conserva il lavoro già fatto.

Riprendi l'input N = 5 e i valori 9, 10, 15, 20, 21. Devi ottenere tre valori dentro [10,20]. Poi pensa al caso N = 0: il ciclo non legge altri numeri e il conteggio rimane zero.

Il programma dei biglietti è più breve, ma usa gli stessi ingredienti: tipi, lettura, espressione e output. Lo useremo per confrontare C++ e C senza dover imparare contemporaneamente un algoritmo nuovo.

Prima svolgi una piccola prova autonoma in C++. Se non riesci a distinguere input, condizione, conteggio e somma, riprendi la 2.04 o la 2.05. La traduzione in C viene dopo: capire la logica è il prerequisito per riconoscere ciò che cambia nella scrittura.

Prova pratica: contare e sommare i positivi

Leggi un intero N fra 0 e 100, poi N interi fra -100 e 100. Mostra prima quanti sono positivi e poi la somma dei soli positivi. Zero non è positivo.

  1. Individua input e due output.
  2. Scegli un contatore dei positivi e un accumulatore per la loro somma.
  3. Leggi un numero a ogni giro e aggiorna entrambi soltanto se è positivo.
  4. Prevedi quattro casi prima di eseguire.

Caso misto

N = 5; -2, 0, 4, 1, -1 → conteggio 2, somma 5.

Nessun dato

N = 0 → conteggio 0, somma 0.

Nessun positivo

N = 3; -1, -2, 0 → conteggio 0, somma 0.

Tutti positivi

N = 2; 3, 7 → conteggio 2, somma 10.

Suggerimento

Prima del ciclo imposta entrambi i risultati a zero. Nel ramo numero > 0 aumenta il conteggio di uno e aggiungi il numero alla somma.

Confronta una soluzione completa

Scarica prova-pratica.cpp

#include <iostream>

int main() {
    int n = 0;
    std::cin >> n;
    int positivi = 0;
    int somma = 0;
    for (int i = 0; i < n; i = i + 1) {
        int numero = 0;
        std::cin >> numero;
        if (numero > 0) {
            positivi = positivi + 1;
            somma = somma + numero;
        }
    }
    std::cout << positivi << '\n';
    std::cout << somma << '\n';
    return 0;
}

Per controllarti: assegna un punto a ciascuno di questi cinque aspetti: lettura corretta dei dati; N iterazioni; esclusione di zero e negativi; conteggio e somma distinti; prove normali e al confine. Se uno dei primi quattro aspetti non funziona, correggilo prima della traduzione in C. Spiega infine due iterazioni usando una traccia.

C e C++: la logica può restare, la scrittura va controllata

C e C++ sono linguaggi distinti. Nel sottoinsieme numerico usato qui, tipi come int e double, assegnazioni, confronti, if, while e for hanno forme simili. Gli strumenti di input e output che abbiamo scelto, invece, cambiano.

Non basta rinominare un file .cpp in .c. In C non usiamo std::cin e std::cout; per questi esempi useremo scanf e printf, dichiarati in <stdio.h>.

Confronta il nuovo programma con biglietti.cpp della 2.02. Input, moltiplicazione e risultato sono gli stessi.

Scarica biglietti-c.c

#include <stdio.h>

int main(void) {
    int quantita = 0;
    double prezzo = 0.0;
    if (scanf("%d %lf", &quantita, &prezzo) != 2) {
        return 1;
    }
    double totale = quantita * prezzo;
    printf("%.2f\n", totale);
    return 0;
}

Capire scanf e printf

scanf("%d %lf", &quantita, &prezzo) prova a leggere due numeri: un intero e un double. I segnaposto nella stringa descrivono il tipo atteso.

  • %d in scanf legge un int.
  • %lf in scanf legge un double.
  • &quantita indica dove scrivere il valore letto. Qui & fornisce l'indirizzo della variabile; non è l'AND logico &&.

scanf restituisce il numero di conversioni riuscite. Ci aspettiamo 2: se il valore restituito è diverso da 2, return 1; interrompe il programma segnalando un input non letto correttamente. Per una sola lettura corretta ci aspetteremmo 1.

printf("%.2f\n", totale); mostra il valore di totale con due cifre dopo il punto decimale, poi va a capo. La formattazione arrotonda ciò che si vede e non trasforma il calcolo in aritmetica decimale esatta.

In printf, %d mostra un intero e %f un valore double; %.2f ne sceglie due cifre decimali. Non copiare automaticamente il formato della lettura nell'output. Per stampare il valore non si usa &.

⚠️

Attenzione

Il formato deve corrispondere al dato

Per leggere un double usa %lf e l’indirizzo della variabile. Un formato errato può produrre un comportamento scorretto anche se il programma compila. Nei dati digitati usa il punto decimale.

int main(void) è la forma usata qui per indicare che main non riceve parametri. Le funzioni in generale e i puntatori saranno studiati più avanti: per ora collega l'indirizzo al compito concreto della lettura.

Laboratorio guidato: eseguire il primo file C

  1. Crea un progetto C o un file biglietti-c.c nell'ambiente predisposto dal docente.
  2. Controlla che la compilazione sia per C, non per C++. Con GNU C puoi usare gcc -std=c11 biglietti-c.c -o biglietti-c.
  3. Compila ed esegui. Inserisci 4 e 2.5, separati da spazio o Invio: l'output è 10.00.
  4. Ripeti con 0 e 2.5: 0.00. Poi con 3 e 7: 21.00.
  5. Confronta i risultati con il programma C++: cambia la presentazione dei decimali, non il valore atteso.
  6. Prova una lettera al posto della quantità: la lettura non completa le due conversioni e il programma termina senza calcolare il totale.

Il controllo sul numero di letture riuscite non verifica tutte le regole del problema: un prezzo negativo resta un numero leggibile. Nei casi ordinari assumiamo quantità intere non negative e prezzi non negativi e piccoli.

Riconoscere un ciclo già scritto

Il programma seguente traduce in C la somma da 1 a N della 2.04. Cerca le parti rimaste uguali: inizializzazioni, condizione e aggiornamenti.

Scarica somma-c.c

#include <stdio.h>

int main(void) {
    int n = 0;
    if (scanf("%d", &n) != 1) {
        return 1;
    }
    int somma = 0;
    int numero = 1;
    while (numero <= n) {
        somma = somma + numero;
        numero = numero + 1;
    }
    printf("%d\n", somma);
    return 0;
}

Con N fra 0 e 100, ripeti 0 → 0, 1 → 1 e 4 → 10. Il risultato è un int, quindi l'output usa %d. La lettura attende una sola conversione.

Esercizio autonomo: il rettangolo in C

Traduci il programma del rettangolo della 2.02. Leggi due double positivi e mostra prima area, poi perimetro, con due cifre decimali. Controlla che entrambe le letture siano riuscite.

Prove: base 5 e altezza 3 → 15.00 e 16.00; base 2.5 e altezza 2 → 5.00 e 9.00. Conserva le parentesi della formula.

Confronta una soluzione completa

Scarica rettangolo-c.c

#include <stdio.h>

int main(void) {
    double base = 0.0;
    double altezza = 0.0;
    if (scanf("%lf %lf", &base, &altezza) != 2) {
        return 1;
    }
    double area = base * altezza;
    double perimetro = 2 * (base + altezza);
    printf("%.2f\n", area);
    printf("%.2f\n", perimetro);
    return 0;
}

Consegna finale: file C++ della prova pratica, file C del rettangolo, input e risultati di ciascuna prova. Presenta un errore che hai corretto spiegando quale test lo ha rivelato.

Autoverifica

Rispondi prima di aprire le indicazioni.

Rinominare un file C++ in .c basta per tradurlo?

No. Occorre usare costrutti e strumenti disponibili in C e compilare per il linguaggio corretto.

Che cosa significa il 2 nel controllo di scanf dei biglietti?

Sono attese due conversioni riuscite: quantità intera e prezzo double.

Perché in scanf scriviamo &prezzo?

La lettura deve sapere dove memorizzare il valore: & fornisce l’indirizzo della variabile.

Una compilazione riuscita conclude la verifica?

No: occorrono dati di prova, confronto con gli output attesi e controllo dei confini.
