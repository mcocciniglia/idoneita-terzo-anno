Metodo di lavoro

Una novità alla volta

Il programma finale contiene molti concetti. Non devi comprenderli tutti insieme: esegui ogni tappa, prevedi l'output e passa alla successiva soltanto quando sai spiegare quella corrente.

🎯

Obiettivi essenziali

  • usare un for per ripetere un'operazione un numero noto di volte;
  • leggere e scrivere un elemento di un array mediante il suo indice;
  • distinguere il compito di main da quello di una funzione;
  • riconoscere dove una variabile è visibile e utilizzabile;
  • ricostruire e spiegare il programma finale senza impararlo a memoria.

La strada che seguiremo

  1. Un dato.

    Leggiamo un nome e lo mostriamo.

  2. Una ripetizione.

    Stampiamo una tabellina con un for.

  3. Una ripetizione dentro un'altra.

    Costruiamo la tabella pitagorica.

  4. Molti dati dello stesso tipo.

    Conserviamo più nomi in un array.

  5. Un numero valido di studenti.

    Ripetiamo l'input con do-while finché il valore rispetta i limiti.

  6. Compiti separati.

    Spostiamo inserimento e stampa in due funzioni.

Tappa 0 — Input di un solo dato

Prima dell'array usiamo una sola variabile. nome contiene una parola letta con cin.

#include <iostream>
#include <string>
using namespace std;

int main() {
    string nome;
    cout << "Inserisci un nome: ";
    cin >> nome;
    cout << "Hai inserito: " << nome << endl;
}

Prova: inserisci Anna. L'output atteso è Hai inserito: Anna. Per ora usiamo nomi senza spazi.

Tappa 1 — La tabellina e il ciclo for

Per stampare dieci prodotti cambia soltanto il moltiplicatore. Il for raccoglie inizializzazione, condizione e aggiornamento.

int numero;
cout << "Quale tabellina vuoi stampare? ";
cin >> numero;

for (int i = 1; i <= 10; i++) {
    cout << numero << " x " << i
         << " = " << numero * i << endl;
}
Leggi il for

i parte da 1; il blocco continua finché i <= 10; dopo ogni giro i++ aumenta i di uno.

Tappa 2 — La tabella pitagorica: due for annidati

Il ciclo esterno sceglie la riga. Per ogni riga, il ciclo interno percorre tutte le colonne.

for (int riga = 1; riga <= 10; riga++) {
    for (int colonna = 1; colonna <= 10; colonna++) {
        cout << riga * colonna << '\t';
    }
    cout << endl;
}
🕒

Immagine mentale

Il ciclo interno riparte

Quando cambia riga, colonna riparte da 1. Con 10 righe e 10 colonne, la moltiplicazione viene eseguita 100 volte.

Attività: porta entrambi i limiti da 10 a 3. Prima di eseguire, scrivi a mano le tre righe attese.

Tappa 3 — Dalla variabile all'array

Tre variabili separate funzionano, ma diventano scomode quando i nomi aumentano. Un array raccoglie più valori dello stesso tipo sotto un solo nome.

string studenti[3];

for (int i = 0; i < 3; i++) {
    cout << "Inserisci il nome dello studente " << i + 1 << ": ";
    cin >> studenti[i];
}

for (int i = 0; i < 3; i++) {
    cout << i + 1 << ") " << studenti[i] << endl;
}

Indice

La prima posizione è 0, non 1.

Numero mostrato

All'utente mostriamo i + 1, così l'elenco parte da 1.

Limite

Per tre elementi gli indici validi sono 0, 1 e 2.

Tappa 4 — Controllare quanti studenti inserire

Il numero deve essere letto almeno una volta. Se non è compreso tra 1 e 100, lo chiediamo di nuovo.

int numeroStudenti;
do {
    cout << "Quanti studenti vuoi inserire? ";
    cin >> numeroStudenti;
} while (numeroStudenti <= 0 || numeroStudenti > 100);

La ripetizione continua se il valore è troppo piccolo oppure troppo grande. Con 100 posti, il valore 100 è valido.

Tappa 5 — Separare i compiti con le funzioni

Il programma svolge tre compiti: controlla il numero, inserisce i nomi e li stampa. main coordina; le due funzioni eseguono i compiti specifici.

void inserisciStudenti(int numeroStudenti);
void stampaStudenti(int numeroStudenti);

Queste sono le dichiarazioni delle funzioni. void indica che la funzione svolge un'azione ma non restituisce un valore. Il parametro numeroStudenti comunica quanti elementi usare.

Tappa 6 — #define e scope

#define NSTUD 100
string studenti[NSTUD];

NSTUD dà un nome al limite massimo. In questo esempio è una costante simbolica elaborata prima della compilazione. Più avanti potrai incontrare anche const; qui riconosciamo la forma usata nel programma di classe.

Scope globale

studenti, dichiarato fuori dalle funzioni, è visibile a tutte le funzioni del file.

Scope locale

i esiste soltanto nel proprio for; numeroStudenti del parametro appartiene alla funzione.

Scelta didattica

L'array globale rende il primo esempio più leggibile. Non significa che ogni array debba essere globale.

💻 Programma finale ricostruito

Il programma conserva la struttura realizzata in classe. Le funzioni sono void perché non restituiscono risultati; il controllo ammette da 1 a 100 studenti.

#include <iostream>
#include <string>
#define NSTUD 100

using namespace std;

void inserisciStudenti(int numeroStudenti);
void stampaStudenti(int numeroStudenti);

string studenti[NSTUD];

int main() {
    int numeroStudenti = 0;

    do {
        cout << "INSERISCI QUANTI STUDENTI VUOI INSERIRE" << endl;
        cin >> numeroStudenti;
    } while (numeroStudenti <= 0 || numeroStudenti > NSTUD);

    inserisciStudenti(numeroStudenti);
    stampaStudenti(numeroStudenti);
}

void inserisciStudenti(int numeroStudenti) {
    for (int i = 0; i < numeroStudenti; i++) {
        cout << "INSERISCI IL NOME DELLO STUDENTE NUMERO "
             << i + 1 << endl;
        cin >> studenti[i];
    }
}

void stampaStudenti(int numeroStudenti) {
    cout << "NOME" << endl;
    cout << "----------------" << endl;

    for (int i = 0; i < numeroStudenti; i++) {
        cout << i + 1 << ")\t" << studenti[i] << endl;
        cout << "----------------" << endl;
    }
}

Attività graduate

  1. Completa: modifica la tabellina affinché stampi i prodotti da 0 a 10.
  2. Prevedi: nella tabella pitagorica 3 × 3, quante volte viene eseguito il ciclo interno in totale?
  3. Correggi: spiega perché i <= numeroStudenti accederebbe a una posizione in più dell'array.
  4. Modifica: aggiungi la funzione void stampaSeparatore() e usala al posto della riga di trattini ripetuta.
  5. Autonomo: crea un array di cinque numeri interi, leggili e stampali nello stesso ordine.
Indicazioni per controllare le attività

La tabellina parte con i = 0. Una tabella 3 × 3 esegue il corpo interno 9 volte. Con numeroStudenti = 3 sono validi gli indici 0, 1 e 2: l'indice 3 è fuori dal gruppo dei tre elementi usati. La nuova funzione non richiede parametri né restituisce valori.

Errori da riconoscere

Partire da 1 nell'array

Il primo indice è 0. Il numero mostrato alla persona può invece partire da 1.

Confondere indice e contenuto

i indica una posizione; studenti[i] è il nome conservato in quella posizione.

Dimenticare l'aggiornamento

Nel for, i++ permette di passare all'elemento successivo.

Restituire un valore inutile

Se una funzione esegue soltanto input o output, void esprime meglio il suo compito.

🧠 Autoverifica finale

Perché il primo indice di un array di 100 elementi è 0 e l'ultimo è 99?

Gli indici contano gli spostamenti rispetto all'inizio: il primo elemento è a spostamento 0. Cento posizioni vanno quindi da 0 a 99.

Quando conviene usare un for?

Quando la ripetizione segue un conteggio chiaro: valore iniziale, condizione e aggiornamento possono stare insieme nell'intestazione.

Che cosa cambia tra il ciclo esterno e quello interno?

Il ciclo esterno sceglie una riga; per ogni sua iterazione, il ciclo interno percorre tutte le colonne.

Che cosa significa void?

Indica che la funzione non restituisce un valore al punto in cui è stata chiamata.

Che cos'è lo scope di una variabile?

È la parte del programma nella quale quel nome è visibile e può essere usato.
