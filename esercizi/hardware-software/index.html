Hardware e software

Allenati a distinguere parti fisiche e programmi e a riconoscere input, elaborazione e output in semplici situazioni quotidiane.

📘 Collegato alle Lezioni 03 e 04 📈 Difficoltà crescente ✅ Soluzioni incluse
📒

Prima di cominciare

Questo quaderno non è una nuova lezione

Serve ad allenare e consolidare quanto studiato nelle Lezioni 03 e 04. Svolgi le attività in ordine e consulta le soluzioni soltanto alla fine.

🧭

Come lavorare

  1. Leggi una consegna alla volta.

    Individua che cosa devi riconoscere o spiegare.

  2. Scrivi la risposta.

    Usa un foglio o un documento e motiva quando richiesto.

  3. Procedi in ordine.

🧠

Breve ripasso

Queste sono le sole idee necessarie per affrontare gli esercizi.

Hardware

Insieme dei componenti fisici del computer.

Software

Parte logica del computer, costituita dai programmi.

Programma

Sequenza di istruzioni per svolgere uno specifico compito.

Input

Dati o comandi inseriti.

Elaborazione

Lavoro svolto dal computer sui dati.

Output

Risultato restituito dal computer.

🤝

Idea fondamentale

Hardware e software collaborano

Il software contiene le istruzioni; l'hardware le esegue concretamente. Uno senza l'altro non è utile.

1

Riconosci hardware o software

Scrivi H se l'elemento è hardware oppure S se è software.

  1. Tastiera
  2. Monitor
  3. Mouse
  4. CPU
  5. Memoria RAM
  6. SSD
  7. Sistema operativo
  8. Browser
  9. Programma di videoscrittura
  10. Calcolatrice del computer
  11. Stampante
  12. Applicazione per ascoltare musica
2

Vero o falso

Scrivi V oppure F. Se una frase è falsa, correggila con poche parole.

  1. La RAM è hardware.
  2. Un browser è software.
  3. Un programma è un oggetto fisico.
  4. Hardware e software possono essere utili separatamente.
  5. La tastiera può fornire un input.
  6. Il monitor può mostrare un output.
  7. La CPU esegue le istruzioni dei programmi.
  8. Un SSD è un programma per conservare dati.
  9. Il software è costituito da programmi.
  10. L'output è il risultato restituito dal computer.
3

Completa le frasi

Usa le parole: hardware, software, programma, istruzioni, input, elaborazione, output. Ogni parola va usata una volta.

  1. L'insieme dei componenti fisici si chiama __________.
  2. La parte logica del computer si chiama __________.
  3. Un __________ è una sequenza di istruzioni.
  4. Le operazioni che il computer deve svolgere sono indicate dalle __________.
  5. I dati o i comandi inseriti costituiscono l'__________.
  6. Il lavoro svolto sui dati si chiama __________.
  7. Il risultato restituito dal computer è l'__________.
4

Collega elemento e funzione

Associa ogni elemento numerato alla funzione indicata da una lettera. Scrivi, per esempio, 1-C.

Elementi

  1. Tastiera
  2. CPU
  3. RAM
  4. SSD
  5. Monitor
  6. Browser

Funzioni

  1. Mostrare risultati.
  2. Conservare dati e programmi.
  3. Inserire dati e comandi.
  4. Eseguire le istruzioni dei programmi.
  5. Permettere di navigare sul Web.
  6. Mantenere temporaneamente disponibili dati e programmi in uso.
5

Trova l'intruso

In ogni gruppo individua l'elemento di categoria diversa e motiva la risposta con una frase.

  1. Monitor, mouse, tastiera, sistema operativo.
  2. Browser, programma di videoscrittura, applicazione musicale, RAM.
  3. CPU, SSD, RAM, calcolatrice del computer.
  4. Tastiera, mouse, monitor, browser.
6

Casi pratici

🧭

Per ogni situazione rispondi alle seguenti domande:

  • Quali elementi hardware sono coinvolti?
  • Quale software viene utilizzato?
  • Qual è l'input?
  • In cosa consiste l'elaborazione? Descrivila in modo generale.
  • Qual è l'output?

1. Consultare una pagina Web

Tommaso apre il browser, scrive un indirizzo con la tastiera e vede la pagina sul monitor.

2. Eseguire un calcolo

Giulia apre la calcolatrice del computer, inserisce 25 + 17 con il mouse e legge il risultato sul monitor.

3. Scrivere una frase

Luca apre un programma di videoscrittura, digita una frase con la tastiera e la vede comparire sul monitor.

4. Ascoltare una canzone

Sara apre un'applicazione musicale, sceglie una canzone con il mouse e ascolta il suono dagli altoparlanti.

7

Risposte brevi

Rispondi a ogni domanda in due o tre frasi.

  1. Qual è la differenza tra hardware e software?
  2. Perché un programma ha bisogno dell'hardware?
  3. Fai tre esempi di hardware e tre esempi di software.
  4. Descrivi un'attività usando le parole input, elaborazione e output.
  5. Perché hardware e software devono collaborare?

6. Casi pratici

Le descrizioni dell'elaborazione possono essere formulate in modo diverso. È sufficiente indicare il lavoro generale svolto dal computer.

  1. Pagina Web: hardware: tastiera e monitor; software: browser; input: indirizzo digitato; elaborazione: il computer esegue il browser e lavora sul comando ricevuto; output: pagina mostrata sul monitor.
  2. Calcolo: hardware: mouse e monitor; software: calcolatrice; input: numeri e operazione scelti; elaborazione: il computer esegue le istruzioni della calcolatrice; output: risultato mostrato sul monitor.
  3. Frase: hardware: tastiera e monitor; software: programma di videoscrittura; input: caratteri digitati; elaborazione: il computer esegue il programma e lavora sui dati inseriti; output: frase mostrata sul monitor.
  4. Canzone: hardware: mouse e altoparlanti; software: applicazione musicale; input: scelta della canzone; elaborazione: il computer esegue l'applicazione e lavora sui dati della canzone; output: suono prodotto dagli altoparlanti.
7. Risposte brevi — Modelli possibili
  1. L'hardware è l'insieme dei componenti fisici del computer. Il software è la parte logica ed è costituito dai programmi.
  2. Un programma ha bisogno dell'hardware perché le sue istruzioni devono essere eseguite concretamente dalle componenti fisiche.
  3. Esempio: tastiera, monitor e CPU sono hardware; browser, calcolatrice del computer e programma di videoscrittura sono software.
  4. Esempio: inserisco due numeri nella calcolatrice come input; il computer svolge l'elaborazione; il totale mostrato è l'output.
  5. Il software indica che cosa fare attraverso le istruzioni. L'hardware esegue concretamente le operazioni necessarie.

Sono corrette anche risposte formulate diversamente, se contengono le stesse idee fondamentali.
